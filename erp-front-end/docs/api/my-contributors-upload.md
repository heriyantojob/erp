# My Contributors Upload API

Endpoint: `POST /stock/add-file`

Used by the pictheme end-user portal at `/{lang}/my-contributors/upload` to create a new contributor asset.

## Request (multipart/form-data)

| Field         | Type                     | Required                 | Description                                                                                    |
| ------------- | ------------------------ | ------------------------ | ---------------------------------------------------------------------------------------------- |
| `file`        | File                     | Yes                      | Binary image upload (PNG, JPG, JPEG, WEBP, SVG, GIF).                                          |
| `title`       | string                   | Yes                      | Human friendly name for the asset.                                                             |
| `description` | string                   | Yes                      | Short description of the upload.                                                               |
| `status`      | number                   | Yes                      | `0` draft, `1` publish, `2` in review, `3` reject.                                             |
| `link`        | string                   | Yes                      | Slug/source string; must be unique once slugified.                                             |
| `tags`        | string[] or comma string | No                       | Keywords attached to the asset.                                                                |
| `isAi`        | boolean                  | No (defaults to `false`) | Marks whether the file is generated by AI models (Midjourney, DALL·E, Stable Diffusion, etc.). |

### `isAi` details

- Accepts `true/false`, `1/0`, or checkbox style values (`on`).
- Defaults to `false` when omitted, so existing non-AI uploads continue to work.
- Stored as a tinyint flag in `stock.is_ai` and exposed in contributor listings to drive AI badges and future filtering.

## Response

`200 OK` with `{ "message": "add file" }` when the upload succeeds. Validation errors return `400` with an `errorList` payload (per existing behavior).

## Display

When `isAi` is true, the UI renders an “AI” badge on the contributor card so viewers can instantly distinguish AI-generated pieces.
